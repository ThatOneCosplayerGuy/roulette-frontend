# Roulette Frontend

Simple browser-based roulette game built with vanilla JavaScript.

## Live Demo

https://ThatOneCosplayerGuy.github.io/roulette-frontend/

## Overview

Small frontend project that simulates a basic European roulette table.
Built mostly for experimenting with UI interactions and browser state.

## Features

* Basic betting system (colors, numbers, etc.)
* Chip management
* Spin animation
* Local storage save/load
* IF YOU ARE READING THIS, IT IS MADE FOR A PROJECT FOR MYSELF, NOT REAL GAMBLING

## Tech Stack

* HTML
* CSS
* JavaScript

## Notes

* Runs entirely in the browser
* State is stored in `localStorage`
* No backend or API
* Some parts are still unpolished
